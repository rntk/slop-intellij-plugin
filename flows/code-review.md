# Code review flow

Code Review is a read-only workspace for exploring an existing codebase scope. It opens as a hub in the editor area, where each review tab offers a grid of tiles: choosing the scope and optionally scheduling background generation, then navigating the code through [summaries](summaries.md), dedicated Hierarchy and Document tabs, topics, charts, a Words tab for the source word cloud, a pannable Code wall, a [Report viewer](report-viewer.md) for Markdown and text reports, and finally chat. A Knowledge view checks docs against the code and distills codebase claims, as described in the [Knowledge flow](knowledge.md). The Charts view gathers charts about the scope; its lines-of-code chart explores one directory at a time with drill-down and path breadcrumbs and lets readers toggle each file or directory's summary or source preview in a second column on the right while highlighting the active entry, while its radar compares how much code each folder or file holds at a chosen level, using source lines or IDE-parsed symbols and comments, and the topics view has a radar of its own. Symbol views distinguish declaration kinds and show which files have symbol data; clicking a legend item isolates that type on the chart.

The Words tab shows the most frequent words in the selected file, folder, or review scope, and offers a **View** selector for **Words** and **Constructs**. The Constructs view charts source constructs (such as branches, loops and literals) the same way, counting them across all code in the scope rather than only changed lines, and sizing them by frequency. Selecting a word or construct opens the files in the scope where it appears. In [Diff Review](diff-review.md), the Words tab instead compares added and removed lines (see the [Words diff flow](diff-words.md)).

Focused tabs and wall chats let readers ask questions grounded in the captured scope, while still allowing supporting reads from the wider project. The Hierarchy and Document views build very large scopes progressively, a page at a time with a link to load more, so huge codebases stay responsive. Their summaries link file paths, line references, and code symbols as the [Report viewer](report-viewer.md) does, with its link and selection context menus, while keeping word tracing. The tool window holds only the active tab's chat and stays hidden until it is opened.
