# Entrypoints flow

Entrypoints helps readers find likely places where execution begins, such as user actions or application startup. Results offer a practical way to begin exploring a project and can also provide starting points for call graphs and flow views.

Entry points for further exploration:

- [EntryPointService.kt](../src/main/kotlin/dev/insight/entrypoints/EntryPointService.kt) — entry point discovery
- [EntryPointsPanel.kt](../src/main/kotlin/dev/insight/entrypoints/EntryPointsPanel.kt) — results interface
