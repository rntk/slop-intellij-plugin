# Prompt constructor flow

Prompt Constructor is a separate workspace for assembling reusable Markdown prompts and appendices. A user selects a library, finds components, and appends, inserts or loads them into a persistent draft. The draft can be previewed, copied, exported or saved back to the library.

Entry points for further exploration:

- [PromptConstructorPanel.kt](../src/main/kotlin/dev/insight/prompts/PromptConstructorPanel.kt) — workbench and tool entry points
- [PromptLibrary.kt](../src/main/kotlin/dev/insight/prompts/PromptLibrary.kt) — Markdown library and composition
